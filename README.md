
# CampusConnect
## College Management and Student Community Portal

CampusConnect is a web-based college portal designed to bring
students, campus activities, academic information and college
resources together in one platform.

## Project Overview

CampusConnect provides a centralized interface where students
can explore campus events, view announcements, interact with
the student community and access campus information.

## Modules

### 1. Dashboard
- Student welcome section
- Upcoming event statistics
- Notice statistics
- Student post statistics
- Quick navigation

### 2. Event Management
- View upcoming events
- Search events

- View event dates and locations

### 3. Notice Board
- Academic announcements
- General announcements
- Event notifications

### 4. Academic Corner
- Study materials section
- Academic calendar section
- Examination updates
- Results and performance section

### 5. Clubs and Societies
- Technical Club
- AI and Robotics Club
- Cultural Society
- Sports Club

### 6. Campus Resources
- Central Library
- Computer Labs
- Medical Facilities
- Classrooms

### 7. Campus Community Feed
- Create student posts
- Character validation

### 8. Student Profile
- Student name

- Academic year

## Installation

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a browser.

## Deployment

The application can be deployed using GitHub Pages.

1. Upload all project files to a GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Select Deploy from a branch.
5. Choose the main branch.
6. Select the root folder.
7. Save the configuration.

## Data Storage

The current version uses browser LocalStorage.

Data is stored locally in the browser and is not shared
between different students or devices.

A centralized backend and database integration are
required for real college-wide deployment.
